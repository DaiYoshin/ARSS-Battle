# ARSSバトル（仮題）

ようせい・メづすりα・メづすりν・ダンクルオステウス・アネリア広報Bot・グレイ・黒猫から選んでCPUと対戦する、ローカルで動く2D格闘ゲームです。

このリポジトリはゲーム本体・完成済み画像・テスト・ビルドスクリプトを収録しています。制作素材・元動画・録画・制作履歴は元の開発フォルダで管理します。

## 起動
配布一式の `sprite-playground.html` をブラウザーで開けばプレイできます。画像も含むためインターネット接続は不要です。
ソース版は `sprite-playground` ディレクトリで `python3 -m http.server 8766 --bind 127.0.0.1` を実行し、http://127.0.0.1:8766/ を開きます。外部公開は不要です。

## 画面の流れ
タイトルの「スタート」→キャラクター・CPU・難易度を選択→「対戦開始」→三本勝負（2本先取）→リザルト→「タイトルへ」。各ラウンド90秒。決着から4秒後に次へ進み、ラウンド間は体力・ガード・位置を回復します。引き分けは本数に数えず同じラウンドを再試合。リザルトには最終スコアと各ラウンドの勝敗を表示します。

## 操作
- ← →：前進・後退。相手を向いたまま移動します。
- Shift＋← →：ダッシュ
- Space：ジャンプ
- A：パンチ／空中パンチ
- S：キック／空中キック
- D長押し：地上ガード（正面のみ）
- Esc：一時停止・再開
- R：再戦
画面のタッチボタンも使用できます。別ウィンドウに移ると自動停止し、戻ったらEscで再開します。

効果音ボタンで開始・命中・防御・決着の音をオン／オフできます。初期状態はオフです。

## ルール
2本先取の三本勝負。以下の体力・時間制限は各ラウンドに適用します。
開始時は「SHOW」→「YOUR」→「C.V.C」を1秒ずつ中央に1語だけ表示し、「FIGHT!」を0.75秒表示して90秒の試合開始。FIGHT!表示中から操作可能。開始・決着演出は背景パネルを使わず文字のみとし、決着時は「FINISH!」を表示。HPゼロでダウン、時間切れは残りHPで勝敗を判定。同HPなら引き分けです。
金色のガード耐久は防御で消耗し、ゼロでガードが崩れます。ガードを解いて時間を置くと回復します。
空中攻撃は一回のジャンプで一回まで。空中攻撃中は進行方向の勢いを保ち、着地すると終了します。
難易度変更は新しい試合を開始します。
「練習・調整」を開くと物理設定と被弾・ダウンのテストを使えます。H/Lのテストキーも開いたときだけ有効です。

## 録画
「録画して再戦」で第1ラウンドから開始し、ラウンドをまたいで録画。2本先取の決着4秒後、リザルトへの移行時に自動停止。途中停止もできます。「動画を保存」を押してローカルに保存します。
録画後はページ内のプレビューでも再生できます。ゲーム画面のみの無音動画です（プレイ中の効果音は録音されません）。対応ブラウザーではMP4/H.264を優先し、非対応ならWebMになります。iPhone実機での動作保証はしていません。

## 開発・検証
Node.jsで `node tests/combat.cjs` 、`node tests/ai.cjs`、`node tests/recording.cjs`、`node tests/input.cjs` を実行。
Python 3で `python3 scripts/build-standalone.py` を実行すると、親ディレクトリに単体HTMLを更新します（追加ライブラリ不要）。


## 試合進行の検証

画面遷移とラウンド進行の検証：`node tests/match-flow.cjs`。ソース版・単体版で2–0/2–1、双方の勝利、引き分け、時間切れ、特殊演出を確認します。

## キャラクター選択

3列の共通キャラパネルから7人を矢印キーで選択。1キーで自分、2キーでCPUのカーソルへ切替。クリック・タップでも選択可能。同キャラ対戦にも対応。Enterまたは対戦開始ボタンで開始。大きな立ち絵は自分が右向き、相手が左向き。

顔サムネイルは中央の共通パネルに配置。PLAYER / CPUまたは1 / 2で操作側を切り替え、同じパネルから選択します。選択中は1P/CPUマーカーを表示。左右の大きな立ち絵は向かい合わせ。

## Canvas内の画面（2026-09-17）

タイトル・キャラ選択・対戦・リザルトを同じ1100×520のCanvasに描画。既存HTMLメニューは読み上げ用の補助として保持。選択は矢印、1/2で自分・CPU切替、Q/Eで難易度、Enterで進む、Escでタイトルへ。クリック・タッチも対応。録画・効果音・練習調整はページ側の補助操作。選択画面の「● 録画」で選択から対戦まで連続録画し、リザルトを2秒含めて自動停止。対戦画面の「録画して再戦」は従来どおり。

ブラウザー検証：PlaywrightとChromiumを導入した環境で `node tests/canvas-menus.cjs`。ソース版と単体版を検証し、確認画像をルートの `.qa-canvas/` に保存。

キャラ選択は中央の7体共通パネルを使用。PLAYER / CPUボタンまたは1 / 2で選択対象を切り替え、同じ顔アイコンから選ぶ。両者が同じキャラを選んだ場合も1P・CPUの両マーカーを表示。

## ステージ

図書館・海辺・近未来都市ハイウェイ・レストランの4種類。キャラ選択下部の背景ボタン、またはZ/Xで選択。選択直後にプレビューし、試合中・ラウンド間・リザルト・再戦で選択を維持。各ステージの違いは背景画像のみで、物理・当たり判定・CPU・技には影響しない。Canvas録画にも選んだ背景を含める。ページ再読込時は図書館。

選択画面の録画は「■ 停止」で手動停止可能。保存リンクはページ側に表示。映像のみで音声は含まない。

## Web公開（Cloudflare Workers）

公開URL: https://arss-battle.yoshindai05.workers.dev/

初回はCloudflare管理画面の「Upload your static files」から公開用ZIPをアップロードし、Worker名 `arss-battle` で公開。更新時は同じWorkerの「New deployment」から再アップロードできます。

`python3 sprite-playground/scripts/build-web.py` で公開用の `dist/arss-battle/` と `arss-battle-cloudflare.zip` を作成します。HTML・CSS・JavaScript・PNGのみを含み、制作素材やテストは公開しません。ローカル単体HTMLへのリダイレクトだけを配布用HTMLから除去し、ゲームの処理・素材はそのままコピーします。

Workersへはリポジトリ直下で `npx wrangler login`、続いて `npx wrangler deploy`。設定は `wrangler.jsonc`。初回のアカウント認証が必要です。更新時も公開用データを再生成してから同じ手順でデプロイします。ZIPは静的ファイルの直接アップロードにも使用できます（ZIP直下にindex.html）。
