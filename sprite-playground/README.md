# ARSSバトルの遊び方

起動・ビルド・テストの手順は [ルートREADME](../README.md) を参照してください。

## 対戦を始める

タイトルで「VS MODE」を選び、自分・CPUのキャラクターを決めます。次のステージ選択で舞台を選んでから「対戦開始」を押します。同じキャラクター同士でも対戦できます。CPUの強さはタイトルの「OPTIONS」で設定します。

キャラクターは、ようせい・メづすりα・メづすりν・ダンクルオステウス・アネリア広報Bot・グレイ・黒猫の7体です。ステージは図書館・海辺・近未来都市ハイウェイ・レストランの4種類で、背景以外のゲームルールは共通です。

| 選択画面のキー | 操作 |
|---|---|
| ← ↑ ↓ → | キャラクターを選ぶ |
| 1 / 2 | 自分 / CPUの選択を切り替える |
| Enter | ステージ選択へ進む |
| Esc | タイトルに戻る |

マウスクリックまたはキーボードで選択できます。難易度の変更だけでは試合は始まりません。

## ステージを選ぶ

キャラクターを決めると、ステージ選択画面へ進みます。図書館・海辺・近未来都市ハイウェイ・レストランから選べます。`Z / X` でも切り替えられ、Enterで対戦を開始します。ステージ固有のルールや演出は、この画面に追加できます。

## モードと設定

- **VS MODE**：CPUとの一試合を遊びます。
- **ARCADE MODE**：選んだ1キャラでCPU3体との対戦後、4戦目で最終ボス「ワカ帝国軍隊長」に挑戦します。軍隊長は体力150で、ナイフ斬りと前蹴りを使うボス専用キャラクターです。勝つと次の相手とステージへ進み、負けると終了します。ステージは進行に合わせて自動で切り替わります。
- **OPTIONS**：CPUの強さを「EASY」「NORMAL」「HARD」から設定します。

## 対戦中の操作

| キー | 操作 |
|---|---|
| ← / → | 移動 |
| Shift＋← / → | ダッシュ |
| Space | ジャンプ |
| A | パンチ / 空中パンチ |
| S | キック / 空中キック |
| D長押し | 地上ガード |
| Esc | 一時停止 / 再開 |
| R | 第1ラウンドから再戦 |

PCのキーボード操作を前提としたゲームです。別ウィンドウに移ると自動停止し、Escで再開します。効果音はボタンで切り替えられ、初期状態はオフです。

## ルール

各ラウンド90秒、2本先取で勝利です。体力がゼロになるとKO、時間切れでは残り体力で勝敗を決めます。同点なら引き分けで、そのラウンドをやり直します。

ラウンド決着から4秒後に次のラウンドまたはリザルトへ進みます。次のラウンドでは体力・ガード・位置が戻ります。

ガードは正面からの攻撃に有効です。ガード耐久がなくなるとガードが崩れ、解除して時間を置くと回復します。空中攻撃は1回のジャンプにつき1回までです。

## 録画

- 選択画面の「● 録画」：選択画面から対戦を通して録画し、リザルトを2秒含めて自動停止します。「■ 停止」で途中停止できます。
- 対戦画面の「録画して再戦」：第1ラウンドから試合を開始して録画し、リザルトへの移行時に停止します。

録画完了後は「動画を保存」で保存でき、ページ内でもプレビューできます。ゲーム画面のみの無音動画で、効果音は含まれません。録画はブラウザー内で行い、動画をサーバーへ送信する処理はありません。

対応ブラウザーではMP4を優先し、それ以外ではWebMを使用します。録画の対応状況はブラウザーによって異なります。

## 練習・調整

「練習・調整」では移動速度、ジャンプの高さ、重力を変更できます。開いている間はHで被弾、Lでダウンを試せます。

## UI改修の見本

ローカルサーバーで `http://127.0.0.1:8766/ui-kit.html` を開くと、書体・配色・ボタン・枠・体力表示の見本を確認できます。

PC版ではCanvas内にタイトル、キャラクター選択、リザルトを描画します。スマホ版を作る場合は、操作方法と画面構成を別途設計した専用サイトとして作成します。

UIの配色は `style.css` の `:root` と `app.js` の `UI` に定義しています。変更時は両方を揃えてください。
